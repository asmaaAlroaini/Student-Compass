# 🧭 لوحة تحكم بوصلة الطالب — Student Compass Dashboard

لوحة التحكم الإدارية والتعليمية المركزية لمنصة وتطبيق **بوصلة الطالب**.

> 📖 **للاطلاع على وثيقة المتطلبات والمواصفات والمعمارية الشاملة:**  
> يرجى فتح ملف [`DASHBOARD_REQUIREMENTS.md`](./DASHBOARD_REQUIREMENTS.md).

---

## 🛠️ التقنيات والمعمارية المستخدمة
- **React 19 + TypeScript + Vite**
- **Tailwind CSS v4 + Shadcn UI + Radix UI**
- **TanStack Query v5 + Zustand**
- **React Router v7**
- **Recharts** للرسوم البيانية والتحليلات
- **Sonner** للتنبيهات والإشعارات الفورية
- مستوحى ومطابق لهيكلية مشروع `File-Archiving-and-Taxpayer-Services-System`.
